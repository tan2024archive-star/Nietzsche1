# اراده به قدرت — Nietzsche Power Puzzle

یک پازل اندرویدی مینیمال. در هر مرحله، برخورد با دیوار آن را حذف می‌کند: مانع صرفاً چیزی برای دور زدن نیست؛ بخشی از مسیر خودفزونی است.

## ساخت APK
این پروژه workflow گیت‌هاب دارد. پروژه را روی GitHub بگذارید، از تب Actions گزینه **Build APK** و سپس **Run workflow** را بزنید. فایل APK در Artifacts قرار می‌گیرد.
